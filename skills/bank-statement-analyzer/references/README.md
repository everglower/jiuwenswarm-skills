# 📄 Bank Statement Analyzer

A Data Science project that simulates and analyzes bank statement transactions using Python.

This project generates a synthetic bank statement dataset and performs complete financial analysis including spending behaviour, anomaly detection, dashboard reporting, and credit score estimation.

## Project Features

* Synthetic Bank Statement Dataset Generation
* Monthly Income vs Expense Analysis
* Expense Category Breakdown
* Spending Heatmaps
* Transaction Anomaly Detection (IQR Based)
* Credit Score Estimation (300–900 Scale)
* Financial Health Insights Dashboard
* Final EDA Report

## Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
