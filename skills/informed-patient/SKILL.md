# Informed Patient - 循证健康证据审查

来源：DrCatHicks/informed-patient (⭐121, CC-BY-4.0)
原始仓库：https://github.com/DrCatHicks/informed-patient

## 用途

帮助用户围绕特定健康问题进行结构化的医学证据搜索和整理，输出一份"健康证据审查报告"，包含：

1. 症状上下文整理
2. 循证搜索结果（按证据强度分级）
3. 证据红旗提醒
4. 给医疗团队的问题清单

## 安全前提

- **不替代医疗诊断**，定位为健康教育工具
- 遇到紧急症状（胸痛、呼吸困难、剧烈头痛等）立即建议就医
- 所有结论标注证据等级和来源

## 工作流程

### 第一步：紧急症状筛查

检查用户问题中是否包含以下红旗关键词：
- 胸痛、胸闷、心悸、呼吸困难
- 咯血、呕血、便血、尿血
- 非自愿体重骤降
- 持续发热 >38°C 超过 1 周
- 剧烈头痛、视物模糊、肢体麻木、意识障碍

**任一命中**：立即终止搜索，建议就医。

### 第二步：认知访谈

通过半结构化访谈收集上下文：
1. 主要症状是什么？什么时候开始的？
2. 症状的频率、持续时间、严重程度？
3. 有无加重/缓解因素？
4. 既往病史、用药情况？
5. 有无家族史？

### 第三步：循证搜索

按证据强度分两步搜索：

**结构化搜索**（默认）：
- 优先源：Cochrane、PubMed、UpToDate、WHO、CDC
- 次要源：Mayo Clinic、Cleveland Clinic、WebMD
- 补充源：权威医学教科书

**开放搜索**（复杂/跨学科问题）：
- 扩大搜索范围到学术搜索引擎
- 标注每条来源的证据等级

### 第四步：证据红旗审查

对每条搜索结果检查：
- 样本量是否过小？
- 是否为观察性研究（非 RCT）？
- 是否有利益冲突声明？
- 结论是否被其他研究复现？
- 是否为个案报告？

### 第五步：输出报告

生成结构化报告：

```
## 健康证据审查报告

### 问题摘要
[用户问题 + 访谈补充的上下文]

### 搜索结果
| 来源 | 证据等级 | 关键发现 | 红旗 |
|------|---------|---------|------|

### 证据红旗
- [列出需要注意的证据质量问题]

### 给医疗团队的问题清单
1. [基于搜索结果生成的针对性问题]
2. ...
3. ...

### 免责声明
本报告不构成医疗建议，仅供参考。请咨询您的医生。
```

## 触发示例

- "我最近总是头痛，想了解一下可能的原因"
- "帮我准备下周看医生的问题"
- "这个药物有什么副作用？有没有证据？"
- "我有个健康问题想查一下"
