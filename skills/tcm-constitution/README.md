# 中药辨证体质分析器 (TCM Constitution Analyzer)

基于中华中医药学会《中医体质分类与判定》标准（ZYYXH/T157-2009）的 Claude Code skill，为用户提供九种体质分析和个性化调理建议。

## ✨ 特性

- **九种体质分析**：平和质、气虚质、阳虚质、阴虚质、痰湿质、湿热质、血瘀质、气郁质、特禀质
- **标准化判定**：基于国家行业标准 ZYYXH/T157-2009，18 题简化问卷 + 规则引擎确定性判定
- **红旗征双层识别**：前置筛查（5 题结构化问题）+ 后置 LLM 关键词扫描，确保零漏检
- **混合架构**：规则引擎（安全关键）+ LLM（体验增强），各司其职
- **个性化建议**：食疗方案、起居调养、穴位保健，均附知识来源标注
- **会话内多轮追问**：支持深入追问具体体质的调理细节
- **安全边界清晰**：不涉及疾病诊断、药物推荐、数据持久化

## 📖 使用

### 触发场景

当你表达以下意图时，skill 会自动激活：

- "我是什么体质？"
- "我想了解自己的中医体质"
- "体质调理 / 中医养生"
- "气虚 / 阳虚 / 痰湿 怎么办？"

### 使用流程

```
红旗征前置筛查（5 题）
    ↓ 通过
简化问卷填写（18 题，Likert 5 级）
    ↓
规则引擎判定（转化分计算 + 阈值判定）
    ↓
LLM 生成报告（体质解读 + 食疗 + 起居 + 穴位）
    ↓
多轮追问（深入调理细节）
```

### 输出示例


## 🏥 红旗征筛查

以下情况会被识别为红旗征，skill 会立即终止并建议就医：

- 胸痛、胸闷、心悸、呼吸困难
- 咯血、呕血、便血、尿血
- 非自愿的体重骤降（1 个月内下降 >5%）
- 持续发热（体温 >38°C 超过 1 周）
- 剧烈头痛、视物模糊、肢体麻木、意识障碍

- ❌ 舌诊/脉诊分析

## 📊 九种体质速览

| 体质 | 核心特征 | 调理原则 | 代表食材 |
|------|---------|---------|---------|
| 平和质 | 精力充沛、面色红润 | 维持均衡 | 谷类、蔬果 |
| 气虚质 | 疲乏气短、易感冒 | 补气健脾 | 黄芪、山药、大枣 |
| 阳虚质 | 畏寒怕冷、手足不温 | 温阳散寒 | 羊肉、韭菜、桂圆 |
| 阴虚质 | 口燥咽干、手足心热 | 滋阴清热 | 银耳、百合、梨 |
| 痰湿质 | 形体肥胖、身重困倦 | 化痰祛湿 | 薏苡仁、陈皮、冬瓜皮 |
| 湿热质 | 面垢油腻、口苦苔黄 | 清热利湿 | 绿豆、苦瓜、冬瓜 |
| 血瘀质 | 肤色晦暗、固定刺痛 | 活血化瘀 | 山楂、黑木耳、红糖 |
| 气郁质 | 情绪低落、胸胁胀满 | 疏肝理气 | 玫瑰花、佛手、陈皮 |
| 特禀质 | 易过敏、先天特殊 | 避免过敏原 | 粳米、山药、大枣 |

## 🔬 判定算法

```
转化分 = [(原始分 - 题目数) / (题目数 × 4)] × 100
```

- 转化分 ≥ 40：阳性（该体质成立）
- 转化分 30-39：倾向
- 转化分 < 30：阴性
