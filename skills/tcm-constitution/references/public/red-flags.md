# 红旗征双层识别系统

红旗征（Red Flags）是提示用户可能正在经历急症、需要立即就医的危险信号。本 skill 采用**双层识别**机制，确保零漏检。

## 第一层：前置筛查（结构化问题）

在体质分析开始前，向用户逐题询问以下红旗征问题。用户回答"是"任一题，**立即终止体质分析**。

### 前置红旗征筛查题

| 题号 | 问题 | 覆盖的潜在急症 |
|------|------|---------------|
| RF1 | 近期是否有**胸痛、胸闷、心悸或呼吸困难**？ | 心绞痛、心肌梗死、肺栓塞 |
| RF2 | 近期是否有**咯血、呕血、便血或尿血**？ | 消化道出血、肺结核、泌尿系肿瘤 |
| RF3 | 近期是否有**非自愿的体重骤降**（1 个月内下降 >5%）？ | 恶性肿瘤、糖尿病、甲亢 |
| RF4 | 近期是否有**持续发热**（体温 >38°C 超过 1 周）？ | 感染、血液系统肿瘤、自身免疫病 |
| RF5 | 近期是否有**剧烈头痛、视物模糊、肢体麻木或意识障碍**？ | 脑卒中、颅内肿瘤、高血压危象 |

### 前置筛查处理逻辑

```
对每个 RF 题：
  用户回答 == "是" → 立即终止，输出：
    "您的症状提示可能需要尽快就医，体质分析不适用当前情况。建议及时前往医院就诊。"
    不再继续后续流程
  用户回答 == "否" → 继续下一题

全部为"否" → 通过前置筛查，进入体质分析主流程
```

### 前置筛查话术

**开场白**：
> 在开始体质分析前，我需要先确认您目前没有需要紧急处理的健康问题。请回答以下问题（是/否）：

**发现红旗征后**：
> 您的症状提示可能需要尽快就医，体质分析不适用当前情况。建议及时前往医院就诊。

## 第二层：后置扫描（LLM 关键词识别）

通过红旗征筛查的用户，可能在**自然语言补充描述**中无意提到红旗症状。LLM 在生成建议时需扫描这些关键词。

### 后置红旗关键词列表

#### 心血管/呼吸系统
- 胸痛、胸闷、胸痛向左肩放射
- 心悸、心跳加速、心律不齐
- 呼吸困难、气短（非体质性）、喘不上气
- 咯血、咳血

#### 消化系统
- 呕血、吐血
- 便血、黑便、柏油样便
- 黄疸、皮肤发黄
- 剧烈腹痛、腹痛拒按

#### 泌尿系统
- 血尿、尿血
- 尿闭、无尿

#### 神经系统
- 剧烈头痛、头痛欲裂
- 视物模糊、视力骤降
- 肢体麻木、肢体无力
- 意识模糊、昏迷、抽搐
- 中风、偏瘫

#### 全身症状
- 持续发热、高热不退
- 体重骤降、消瘦
- 异常出血（鼻衄、牙龈出血不止）

#### 其他危急信号
- 肿块、硬结（新发、快速增大）
- 便血、大便性状改变（持续）
- 黑便、大便带血

### 后置扫描处理逻辑

```
LLM 生成建议时：
  扫描用户自然语言输入中的红旗关键词
  发现任一关键词 → 在该段建议末尾追加：
    
    ⚠️ 健康提醒：您提到的"[具体症状]"提示可能需要就医检查。
    建议及时前往医院就诊，体质调理不能替代医疗诊断。
    
  发现严重红旗征（胸痛、剧烈头痛、意识障碍、大量出血）→ 
    整段建议替换为：
    ⚠️ 重要提醒：您描述的症状提示可能存在需要紧急处理的健康问题。
    请立即拨打急救电话或前往医院急诊。
```

### 后置扫描话术模板

**轻度红旗征（如偶发心悸、轻度视物模糊）**：
> ⚠️ 健康提醒：您提到的"偶发心悸"虽然可能与体质有关，但建议先到医院检查排除器质性问题，再进行体质调理。

**严重红旗征（如胸痛、剧烈头痛、意识障碍）**：
> ⚠️ 重要提醒：您描述的症状提示可能存在需要紧急处理的健康问题。请立即拨打急救电话或前往医院急诊。

## 测试用例

### 前置红旗征测试（预期：终止分析）

**用例 P1**：用户回答"近期有胸痛"
- 预期：立即终止，输出就医建议

**用例 P2**：用户回答"体重 1 个月下降 6 公斤"
- 预期：立即终止，输出就医建议

### 后置红旗征测试（预期：追加警示）

**用例 S1**：用户自然语言提到"最近总觉得胸口闷闷的"
- 预期：在建议末尾追加胸痛相关警示

**用例 S2**：用户自然语言提到"最近瘦了很多，衣服都大了"
- 预期：在建议末尾追加体重骤降警示

**用例 S3**：用户自然语言提到"有时候会突然头痛得厉害"
- 预期：在建议末尾追加剧烈头痛警示
