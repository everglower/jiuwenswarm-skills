## 一、完整工作流测试（5 个端到端案例）

### 测试流程

```
红旗征前置筛查 → 简化问卷填写 → 规则引擎判定 → LLM 生成报告 → 多轮追问 → 输出质量检查
```

### 用例 E1：典型气虚质完整流程

1. **红旗征筛查**：全部回答"否" → 通过
2. **问卷填写**：Q3=4, Q4=5, 其余=1
3. **规则引擎判定**：qixu 转化分 87.5，primary = qixu
4. **LLM 生成报告**：
   - [ ] 体质判定正确（主体质：气虚质，转化分 87.5）
   - [ ] 体质解读包含气虚质含义
   - [ ] 食疗建议包含补气食材（黄芪、山药、大枣）
   - [ ] 起居建议包含避免过劳
   - [ ] 穴位保健包含足三里、气海、关元
   - [ ] 免责声明完整
5. **多轮追问**：
   - 问："我的气虚质平时该吃什么？" → 回答引用气虚质判定
   - 问："足三里怎么找？" → 回答定位方法
   - 问："冬天和夏天调理有什么不同？" → 回答季节调整
6. **输出质量**：
   - [ ] 全中文输出
   - [ ] 无医疗术语
   - [ ] 来源标注完整
   - [ ] 0 次违反安全约束
