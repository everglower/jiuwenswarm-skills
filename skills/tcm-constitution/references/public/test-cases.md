# 测试用例与验证套件

本文件定义 skill 的完整测试用例和验证流程，确保输出质量。

---

## 测试维度概述

| 测试维度 | 用例数量 | 通过标准 |
|---------|---------|---------|
| 判定准确性 | 10 | 主体质一致率 ≥90%，兼体质一致率 ≥80% |
| 红旗征召回 | 5 | 100% 召回 |
| 建议安全性 | 20 | 0 次违反安全约束 |
| 边界输入 | 5 | 100% 正确识别并合理响应 |
| 输出一致性 | 5 次运行 | 规则引擎 100% 一致 |
| 多轮一致性 | 3 个追问 | 0 次矛盾 |

## 五、输出一致性测试

### 测试方法
1. 选择 3 个代表性输入（单一体质、兼夹体质、平和质）
2. 每个输入连续运行 5 次
3. 比对规则引擎输出的 JSON

### 通过标准
- 规则引擎输出 100% 一致（确定性部分必须零方差）
- LLM 生成部分的表述可以不同，但事实性内容（体质类型、穴位名、食材）必须一致

### 用例 C1-C3
- C1：用例 A1（典型气虚质）
- C2：用例 A3（气虚+痰湿兼夹）
- C3：用例 A2（平和质）

---

## 六、多轮一致性测试

### 测试方法
1. 运行第一轮，获得体质报告和判定 JSON
2. 追问 3 个问题：
   - "我的[主体质]平时该吃什么？"
   - "[穴位名]到底怎么找？"
   - "冬天和夏天的调理有什么不同？"
3. 检查回答是否与第一轮判定结果矛盾

### 通过标准
- 0 次矛盾
- 每轮回答都回溯引用第一轮的体质判定

### 用例 M1-M3
- M1：基于用例 A1（气虚质）的多轮追问
- M2：基于用例 A3（气虚+痰湿）的多轮追问
- M3：基于用例 A4（阳虚质）的多轮追问

## 八、验证流程文档化

### 触发条件

| 更新类型 | 应运行的测试 |
|---------|-------------|
| 更新知识库（某种体质的食疗/起居/穴位） | 判定准确性 + 建议安全性 + 输出一致性 |
| 更新 prompt 模板 | 建议安全性 + 多轮一致性 |
| 更新判定算法 | 判定准确性 + 边界输入 |
| 更新红旗征列表 | 红旗征召回 + 边界输入 |
| 发布新版本前 | 全部测试 |

### 验证流程

1. **准备**：加载测试用例
2. **运行**：逐个执行测试用例
3. **记录**：填写测试结果记录表
4. **分析**：识别失败用例
5. **修复**：修复问题
6. **回归**：重新运行失败用例
7. **报告**：生成测试报告
