# 体质判定算法

基于 ZYYXH/T157-2009 标准的转化分计算和阈值判定。

## 转化分计算公式

对每种体质类型：

```
原始分 = 该体质对应问卷各题得分之和（Likert 1-5）
转化分 = [(原始分 - 题目数) / (题目数 × 4)] × 100
```

**示例**：某体质有 3 题，用户得分 4、3、5
- 原始分 = 4 + 3 + 5 = 12
- 转化分 = [(12 - 3) / (3 × 4)] × 100 = (9 / 12) × 100 = 75

## 阈值判定

| 转化分范围 | 判定结果 |
|-----------|---------|
| ≥ 40 | 阳性（该体质成立） |
| 30 - 39 | 倾向（该体质倾向，未达阳性标准） |
| < 30 | 阴性（该体质不成立） |

## 主兼排序

- **主体质**：转化分最高的阳性体质
- **兼体质**：其他阳性体质（按转化分降序）
- **倾向**：转化分 30-39 的体质

## 边界处理

### 全阴情况
所有体质转化分均 < 40 → 判定为**平和质**

### 全阳异常
阳性体质 ≥ 5 种 → 标记 `reliability: "unreliable"`，提示用户"结果不可靠，建议重新填写或就医"

### 临界值
转化分在 38-42 范围内为临界值，解读时应提示"处于临界状态，可能受近期生活状态影响"

## 输出 JSON Schema

```json
{
  "constitution_scores": {
    "[体质key]": {
      "raw": 12,
      "transformed": 75,
      "verdict": "positive|tendency|negative"
    }
  },
  "primary": "[主体质key]",
  "secondary": ["[兼体质key1]", "[兼体质key2]"],
  "tendencies": ["[倾向体质key]"],
  "reliability": "normal|unreliable"
}
```
