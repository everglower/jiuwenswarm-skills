# 阳虚质（Yang Deficiency Constitution）

阳虚质是由于阳气不足、失于温煦，以畏寒怕冷、手足不温等虚寒表现为主要特征的体质状态。

## 体质定义

### 国标原文
阳气不足，以畏寒怕冷、手足不温等虚寒表现为主要特征的体质状态。

### 现代解释
阳虚质的核心是"阳气"不足，表现为热量低下、畏寒怕冷、新陈代谢减慢。常见于长期贪凉、久病体虚、年老体弱的人群。

## 核心症状

- 畏寒怕冷，手足不温（比别人更怕冷）
- 喜热饮食，吃凉的东西不舒服
- 精神不振，面色偏白
- 大便溏薄，小便清长
- 舌质淡胖，苔白，脉沉迟
- 性格沉静、内向

## 判定阈值

- 转化分 ≥ 40：阳虚质成立
- 转化分 30-39：阳虚质倾向

## 食疗方案

### 推荐原则
阳虚质的食疗重点是**温阳散寒**，选用甘温助阳的食材，严格忌食寒凉生冷。

### 推荐食材
- **羊肉**：温中暖肾，补气养血，为"温阳第一肉"
- **韭菜**：温中行气，散瘀活血，又名"起阳草"
- **桂圆**：补心脾，益气血，温阳而不燥
- **生姜**：温中散寒，解表发汗
- **核桃**：补肾温肺，润肠通便
- **虾**：补肾壮阳，通乳抗毒
- **胡椒**：温中散寒，醒脾开胃

### 推荐搭配
- **当归生姜羊肉汤**：当归15g、生姜30g、羊肉500g，炖煮食用，温中补血
- **韭菜炒虾仁**：韭菜100g、虾仁100g，温肾助阳
- **桂圆红枣茶**：桂圆肉10g、大枣5枚，煮水代茶
- **核桃粥**：核桃仁30g、粳米100g，补肾温肺

### 禁忌食材
- **寒凉食材**：冷饮、冰品、西瓜、梨、柿子、苦瓜、绿豆
- **生冷海鲜**：生鱼片、生蚝（未经烹饪）
- **寒性水果**：香蕉、柚子、猕猴桃
- **过度清热**：大量绿茶、菊花茶

[来源：ZYYXH/T157-2009、《中医养生学》、《景岳全书》]

## 起居建议

- 作息：早睡晚起（冬季），保证充足睡眠，避免熬夜伤阳
- 季节：**冬季特别注意保暖**，腰腹部、足部重点保护；**夏季避免贪凉**，空调温度不宜过低（≥26°C）
- 运动：适合有氧运动（如慢跑、快走、跳绳），促进阳气生发，避免大汗淋漓
- 情志：保持积极乐观，避免抑郁消沉（抑郁伤阳）
- 注意事项：避免久坐寒湿之地，避免夜间外出受寒

[来源：《中医养生学》、《景岳全书》]

## 穴位保健

### 命门
- 定位：位于腰部，后正中线上，第2腰椎棘突下凹陷中
- 手法：用掌根按揉，或艾灸
- 频次：每日1次，每次5-10分钟
- 功效：温肾助阳，强腰固本

### 肾俞
- 定位：位于腰部，第2腰椎棘突下，旁开1.5寸
- 手法：用拇指按压，或艾灸
- 频次：每日1次，每次3-5分钟
- 功效：补肾壮阳，强腰利水

### 关元
- 定位：位于下腹部，前正中线上，当脐中下3寸
- 手法：用掌根按揉，或艾灸
- 频次：每日1次，每次5-10分钟
- 功效：培肾固本，温阳益气

[来源：《中国药典》、《中医基础理论》]

## 调养要点

阳虚质的核心是**温阳散寒**：
1. 饮食以甘温助阳为主，严格忌食寒凉生冷
2. 起居避寒就温，冬季特别注意保暖
3. 运动促进阳气生发，避免大汗伤阳
4. 情志保持积极乐观，避免抑郁消沉
5. 可配合艾灸命门、肾俞、关元，温补肾阳
