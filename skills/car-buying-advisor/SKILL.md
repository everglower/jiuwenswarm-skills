## 工作流程

### Phase 1: 需求画像（必做，5 维度）

从用户描述提取，缺失的关键信息最多问一轮：

```
[预算]     裸车预算区间？落地预算？（落地 ≈ 裸车价 × 1.12，新能源免购置税）
[用途]     通勤距离？家庭人数？偶尔长途？商务接待？越野？
[动力]     燃油/混动/插混/纯电？有无家充条件？牌照限制？
[偏好]     品牌倾向？外观风格？智能化需求？保值率优先？
[地区]     所在城市（影响牌照政策、补贴、路况、4S店覆盖）
```

### Phase 2: 平台数据调研（必做，4 轮搜索）

**第 1 轮 -- 候选车型发现**（2-3 次搜索）

```
WebSearch 查询：
1. "{预算}万 {车型类别} 推荐 site:autohome.com.cn"  -- 汽车之家推荐文章
2. "{预算}万 {动力类型} {车型类别} 值得买 site:dongchedi.com"  -- 懂车帝选车
3. "{用途关键词} {预算}万 车型推荐 2024 2025"  -- 通用搜索补充
```

目标：收集 8-12 款候选车型，记录每款的指导价区间。

**第 2 轮 -- 价格行情调研**（每款候选车 1 次搜索）

```
WebSearch 查询（逐个车型）：
"{车型} 落地价 优惠 行情 site:dongchedi.com"
```

获取数据：
- 指导价 vs 实际成交价
- 当前优惠幅度（按城市区分）
- 落地价构成（裸车+税+保险+上牌）

**淘汰规则**：实际落地价超出用户预算的，直接淘汰。

**第 3 轮 -- 口碑与投诉调研**（保留的车型各 2 次搜索）

```
WebSearch 查询 A（口碑）：
"{车型} 口碑 优缺点 site:koubei.autohome.com.cn"

WebSearch 查询 B（投诉）：
"{车型} 投诉 通病 故障 site:12365auto.com"
```

获取数据：
- 车主口碑评分（1-5分）及高频好评/差评关键词
- 投诉量及投诉类型分布（发动机/变速箱/电气/车身）
- 是否有批量通病（如某批次变速箱顿挫）

**淘汰规则**：
- 口碑评分 < 4.0 淘汰
- 投诉销量比异常高（> 同级均值 2 倍）淘汰
- 存在严重安全通病淘汰

**第 4 轮 -- 深度评测调研**（最终保留 3-5 款，各 1 次搜索）

```
WebSearch 查询：
"{车型} 深度评测 试驾 site:pcauto.com.cn OR site:autohome.com.cn"
```

获取数据：
- 底盘/操控/静音/空间专业评价
- 同级别横评排名
- 亮点和短板的专业描述

### Phase 5: 购车策略（必做）

**1. 时机策略**
```
| 时间节点 | 优惠力度 | 原因 |
|---------|---------|------|
| 月底最后3天 | ★★★★ | 销售冲量考核 |
| 季末（3/6/9/12月） | ★★★★☆ | 季度考核 |
| 年底11-12月 | ★★★★★ | 年度冲量+清库存 |
| 车展期间 | ★★★☆ | 集中优惠但需防套路 |
| 改款前1-2月 | ★★★★ | 老款清库 |
```

**2. 谈判策略**
- 先在懂车帝/汽车之家查本地经销商报价，询价 3 家以上 4S 店
- 谈落地价（含税险），不谈裸车价（防加装）
- 优惠 = 现金优惠 + 置换补贴 + 金融贴息 + 装潢礼包
- 加装件成本仅为报价的 20-30%，可谈掉或折现
- 保险可自己买（4S 店通常加价 20-40%）

**3. 新能源专属检查**（如适用）
- 家充桩：确认小区物业同意安装、电表容量足够
- 电池质保：首任车主终身质保？衰减到多少%可换？
- 冬季续航：搜索 "{车型} 冬季 续航 实测" 获取真实数据
- 公共充电：用户住址/公司 3km 内充电桩密度

**4. 验车清单**（提车时用）
```
□ 外观：漆面无划痕、色差，车身无凹陷
□ 生产日期：铭牌日期 < 3个月（超 6 个月为库存车）
□ 轮胎：品牌/型号与配置单一致，磨损正常
□ 玻璃：所有车窗日期一致或接近
□ 内饰：座椅无褶皱磨损，屏幕无划痕
□ 功能：空调、音响、车窗、天窗、座椅调节全部测试
□ 仪表：启动后无故障灯常亮
□ 随车工具：三角牌、反光背心、备胎/补胎液、工具包
□ 文件：合格证、一致性证书、发票、保险单、使用手册
□ PDI 检测报告：要求 4S 店提供
```

## 注意事项

- **数据时效性**：价格和优惠变化快，所有数据标注搜索日期，并注明"以当地4S店实际报价为准"
- **政策差异**：购置税减免、地方补贴、牌照政策各地不同，提醒用户查询当地最新政策
- **数据源透明**：每个关键数据点标注来源平台，用户可自行验证
- **不推经销商**：不推荐具体某家 4S 店
- **安全第一**：安全配置（AEB、气囊数、车身结构）作为硬性筛选条件
- **交叉验证**：口碑/投诉/评测数据至少交叉 2 个平台，单一来源的结论标注"仅基于单一来源"
