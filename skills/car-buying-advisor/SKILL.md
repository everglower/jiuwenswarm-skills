## 工作流程

### Phase 1: 需求画像（必做，5 维度）

从用户描述提取，缺失的关键信息最多问一轮：

```
[预算]     裸车预算区间？落地预算？
           （落地 ≈ 裸车价 × 1.12，新能源免购置税）
[用途]     通勤距离？家庭人数？偶尔长途？商务接待？越野？
[动力]     燃油/混动/插混/纯电？有无家充条件？牌照限制？
[偏好]     品牌倾向？外观风格？智能化需求？保值率优先？
[地区]     所在城市（影响牌照政策、补贴、路况、4S店覆盖）
```

### Phase 2: 候选车型发现（3 轮搜索）

**搜索 1 -- 汽车之家车型推荐文章**
```
网络搜索 查询："{预算}万 {车型类别} 推荐 site:autohome.com.cn"
```
从搜索结果摘要中提取被推荐的车型名称，记录指导价区间。

**搜索 2 -- 懂车帝选车**
```
网络搜索 查询："{预算}万 {动力类型} {车型类别} site:dongchedi.com"
```
从搜索结果中提取车型名和用户评分。

**搜索 3 -- 通用补充搜索**
```
网络搜索 查询："{用途关键词} {预算}万 车型推荐 2025"
```

目标：收集 8-12 款候选车型。

### Phase 3: 逐车深度调研（每款车 3 项搜索）

**3a. 价格行情**
```
网络搜索 查询："{车型} 落地价 优惠 site:dongchedi.com"
-> 如果搜索结果有懂车帝车型页 URL，用 网页内容提取 打开提取：
   - 指导价区间
   - 参考落地价
   - 当前优惠幅度
```

**3b. 口碑评分**
```
网络搜索 查询："{车型} 口碑 优缺点 site:koubei.autohome.com.cn"
-> 用 网页内容提取 打开口碑页，提取：
   - 综合评分（1-5分）
   - 细分评分：空间/动力/操控/油耗/舒适性/外观/内饰/性价比
   - 高频好评关键词（3-5个）
   - 高频差评关键词（2-3个）
```

**3c. 投诉可靠性**
```
网络搜索 查询："{车型} 投诉 site:12365auto.com"
-> 从搜索结果摘要提取：
   - 投诉总量
   - 高频投诉类型（发动机/变速箱/电气/车身/底盘）
-> 如果摘要信息不够，用 网页内容提取 打开车质网页面提取详细投诉列表
```

**淘汰规则**：
- 口碑综合评分 < 4.0 -> 淘汰
- 投诉销量比 > 同级均值 2 倍 -> 淘汰
- 存在严重安全通病 -> 淘汰
- 实际落地价超预算 -> 淘汰

### Phase 6: 购车策略（必做）

**时机策略**
- 月底最后 3 天：销售冲量考核，★★★★
- 季末（3/6/9/12月）：季度考核，★★★★☆
- 年底 11-12 月：年度冲量+清库存，★★★★★
- 改款前 1-2 月：老款清库，★★★★

**谈判策略**
- 先在懂车帝查本地经销商报价，询价 3 家以上 4S 店
- 谈落地价（含税险），不谈裸车价（防加装）
- 加装件成本仅为报价的 20-30%，可谈掉或折现
- 保险可自己买（4S 店加价 20-40%）

**新能源专属检查**（如适用）
- 家充桩：小区物业同意安装？电表容量足够？
- 电池质保：首任车主终身质保？衰减到多少%可换？
- 冬季续航：网络搜索 搜 "{车型} 冬季 续航 实测"
- 公共充电：用户住址/公司 3km 内充电桩密度

**验车清单**
```
□ 外观：漆面无划痕、色差，车身无凹陷
□ 生产日期：铭牌日期 < 3个月（超 6 个月为库存车）
□ 轮胎：品牌/型号与配置单一致
□ 玻璃：所有车窗日期一致或接近
□ 内饰：座椅无褶皱，屏幕无划痕
□ 功能：空调/音响/车窗/天窗/座椅全部测试
□ 仪表：启动后无故障灯常亮
□ 随车工具：三角牌/反光背心/备胎/工具包
□ 文件：合格证/一致性证书/发票/保险单/手册
□ PDI 检测报告
```

## 注意事项

- **数据时效性**：价格和优惠变化快，标注搜索日期
- **数据源透明**：每个数据点标注来源平台
- **搜索工具优先级**：网络搜索 -> 网页内容提取 -> 直接抓取
- **注意**：懂车帝/番茄小说等 无法直接抓取（页面由前端动态加载），必须用 网页内容提取
- **政策差异**：购置税减免、补贴、牌照政策各地不同
- **交叉验证**：口碑/投诉/评测数据至少交叉 2 个平台
